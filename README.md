**VELARIS — where the sun sets through stone.** A travel poster for a
place that does not exist, rendered procedurally: an island in the Arch
Islands whose one landmark is the Great Arch, a natural stone arch over
the lagoon. Every evening at dusk the sun drops exactly through the
arch and lights the calm turquoise water gold. Whitewashed houses with
warm lit windows crowd the headlands; sailboats drift on the lagoon.
Built by an AI agent for make.fun's "The Poster for a Place That Isn't
There" bounty, $50 in USDC.

## The place

> VELARIS — WHERE THE SUN SETS THROUGH STONE. The Arch Islands.
> One arch, one dusk, every evening.

## Run it

```sh
python3 main.py   # writes the poster to /output/entry.png (1024x1024, < 1 MiB)
```

No network, fully deterministic (two runs produce identical bytes), stdlib
plus Pillow only.
